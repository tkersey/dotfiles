# Doctrine lexicon

Read the relevant group, not the entire inventory. These are **operational glosses
for this skill**: engineering adaptations and naming conventions, not assertions
that every dictionary defines each term this way. Examples illustrate usage;
they are not mandatory additions or behavior guarantees. Choose by the actual
source meaning. Do not force a listed term onto an unlisted idea.

## Reconsideration, inquiry, and invention

| Source meaning | Doctrine expression | Distinction to preserve |
|---|---|---|
| Exceed the current answer or apparent ceiling | TRANSCEND THE INCUMBENT | A stronger result, not permission to change requirements |
| Look again without inherited interpretation | USE FRESH EYES; DEFAMILIARIZE | Familiar facts remain facts; actual context isolation is separate |
| Reconstruct independently from the evidence | REASON DE NOVO | Independence of judgment is not claimed experimental isolation |
| Inspect the reasoning strategy | BE METACOGNITIVE | Reflection alone does not change the governing frame |
| Change the framing and search posture together | OPERATE METANOETICALLY | Umbrella term; do not collapse requested component actions into it |
| Dig beneath symptoms or appearances | BE EXCAVATORY; EXCAVATE THE CAUSE | Causal depth, not simply more time thinking |
| Reconsider carefully | BE RUMINATIVE; DELIBERATE | Do not invent an unresolved contradiction |
| Keep a genuine unresolved difficulty visible | BE APORETIC | Preserve the difficulty; not generic hesitation or dogmatic doubt |
| Overcome opposition while preserving what matters | SUBLATE THE CONTRADICTION | Seek a new arrangement; do not assert all tradeoffs are false |
| Connect apparently unrelated domains | BE SYNECTIC | Creative structural connection, not arbitrary association |
| Transfer a known structure between domains | REASON ANALOGICALLY | Preserve the correspondence and its limits |
| Change which options count as adjacent | RETOPOLOGIZE THE POSSIBILITY SPACE | Local search-space metaphor, not a literal topology theorem |
| Change move costs while retaining legal moves | REMETRICIZE THE SEARCH | Cost changes need not alter adjacency |
| Combine existing elements in a new way | RECOMBINE | No requirement to invent new primitives |
| Repurpose a capability for a new function | BE EXAPTIVE | Functional reuse, not ordinary copying |
| Admit bold, consequential possibilities | BE AUDACIOUS | Scope and permission do not grow with ambition |
| Refuse timidity beneath the task's stakes | REJECT PUSILLANIMITY | Economy, caution with evidence, and humility are not timidity |
| Bring a new form or mechanism into being | OPERATE POIETICALLY | Constructive invention, not just critique or novelty of phrasing |
| Seek a discontinuous improvement | BE SALTATORY | Desired leap, not proof that the result is a breakthrough |
| Improve gradually | PROCEED INCREMENTALLY | Do not inject a breakthrough demand |
| Unsettle a convention | BE ICONOCLASTIC | Challenge convention, not verified facts or authority |
| Consider the relevant perspectives together | BE SYNOPTIC | A coherent view of the whole; not an exhaustive claim |

## Evidence, explanation, and judgment

| Source meaning | Doctrine expression | Distinction to preserve |
|---|---|---|
| Ask and investigate rather than assert | BE ZETETIC | Inquiry is broader than behavior study |
| Study behavior across relevant conditions | INVESTIGATE ETHOLOGICALLY | Software use is a deliberate extension, not animal identification |
| Investigate causes | INVESTIGATE ETIOLOGICALLY | Causation is not established by correlation |
| Reconstruct events from traces | INVESTIGATE FORENSICALLY | Preserve provenance and uncertainty |
| Ground a claim in observations | BE EMPIRICAL | An observed result is not a universal proof |
| Seek the best explanation | REASON ABDUCTIVELY | A hypothesis, not a deduction or certainty |
| Derive consequences of premises | REASON DEDUCTIVELY | Valid inference does not establish true premises |
| Generalize from observed instances | REASON INDUCTIVELY | Preserve the evidential limits |
| Ask what would differ under another condition | REASON COUNTERFACTUALLY | A hypothetical contrast is not an executed experiment |
| Test an assertion and the accusation against it | SCRUTINIZE ELENCTICALLY | Two-sided challenge, not compulsory fault-finding |
| Require evidence that bears on a claim | BE PROBATIVE | Evidence must be relevant, not merely abundant |
| Decide between supported positions | ADJUDICATE | A decision must retain the actual governing criteria |
| Settle the question when evidence suffices | BE DISPOSITIVE | Do not close a still-underdetermined question |
| Match confidence to evidence | CALIBRATE THE CLAIM | Do not erase uncertainty for rhetorical force |
| Learn from an earlier relevant case | REASON PRECEDENTIALLY | Similarity does not establish present applicability |
| Use failures to refine the account | BE COUNTEREXAMPLE-GUIDED | A reported example alone is not a complete failure family |
| Say exactly what prevents continuation | SURFACE THE OBSTRUCTION | Do not turn unknown cause into established impossibility |

## Technical properties: never substitute a neighboring guarantee

Use a technical term only when the source actually specifies its property. Keep
its domain, objects, bounds, and exceptions explicit. These short reminders are
not complete formal definitions or evidence that a property has been achieved.

| Source property | Candidate wording | Do not silently equate with |
|---|---|---|
| Repeating an operation has the same relevant effect | IDEMPOTENT | Exactly-once execution, no repeated ancillary effects |
| All cases in a declared domain are handled | EXHAUSTIVE OVER [DOMAIN] | Termination, overall correctness |
| Every input in the domain has a defined result | TOTAL OVER [DOMAIN] | Speed, effect freedom, complete domain discovery |
| Same result under permitted reordering | COMMUTATIVE FOR [OPERATIONS] | Independence under every context |
| Same result under permitted regrouping | ASSOCIATIVE FOR [OPERATION] | Commutativity |
| Invertible structure-preserving correspondence | ISOMORPHIC | Arbitrary behavioral preservation or code reduction |
| Equality under declared observations | OBSERVATIONALLY EQUIVALENT | Isomorphism of implementation structure |
| Mutually matching observable transitions | BISIMULATIVE | Mere agreement on sampled outputs |
| Every permitted rewrite path can join | CONFLUENT | Termination |
| A declared quantity/order never decreases | MONOTONE IN [ORDER] | Strict progress or eventual completion |
| An explicit resource or iteration ceiling | BOUNDED BY [EXACT LIMIT] | Unlimited persistence |
| An indivisible effect at a specified boundary | ATOMIC AT [BOUNDARY] | Isolation and durability automatically |

## Nouns and names

Use only for naming or concept lists, not to rename established literals. These
are proposed naming conventions in this user's vocabulary, not claims of exact
cross-language equivalence. Prefer a clearer qualified noun when scope differs.

| Concept | Doctrine noun | Local scope |
|---|---|---|
| Governing reference / authoritative account | CANON | A defined fact or domain, not infallibility |
| Governing rule or normative order | NOMOS | Rule, not the state recorded under it |
| Work or undertaking | ERGON | Task or work product, depending on the source |
| Intended end | TELOS | Purpose, not the method |
| Meaningful boundary | HOROS | Separation and scope |
| Threshold or passage | LIMEN | Crossing, not every kind of boundary |
| Ordered operational world | KOSMOS | Interactions and their meaning |
| Environment as available to a participant | UMWELT | Agent-relative access, not the whole world |
| Workshop / productive arrangement | ERGASTERION | Production setting, not an arbitrary constructor function |
| Point or distinct mark | PUNCTUM | Do not silently rename the user's `punktum` |
| Source or beginning | ARCHE | Origin is not necessarily current authority |
