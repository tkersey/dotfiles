# Universalist Subagent Orchestration

## Disclosure contract

**Load when:** the current session or applicable repository instructions
authorize subagent use and independent Universalist questions warrant this
workflow's role-distinct packet contract. Do not impose a second explicit-request
gate. A user request can select this workflow when higher-priority instructions
permit it.

**Do not load for:** ordinary implicit activation, one bounded seam, or a task
whose dominant uncertainty can be resolved by the root. A bounded delegation
that does not need this workflow's packet contract also does not load it.

## Authority

The root agent owns:

- requirement interpretation;
- current-context and comparison-universe binding;
- role selection and prompts;
- packet freshness;
- synthesis and route selection under standalone root authority;
- Actuating handoff when Actuating owns selection;
- write ordering and conflict resolution;
- the Boundary Artifact Contract candidate;
- the root receipt when independent durability requires one;
- user-facing conclusions and closure.

Child agents do not choose routes, authorize mutation, emit competing receipts,
or recursively spawn agents.

## Roster

Read `team-routing.md` and use the smallest sufficient roster. Prefer read-only
specialists. Do not fan out merely because several agents exist.

Give each agent one bounded task-grounded question with required behavior,
observations, evidence, and constraints. An architectural axis and typed hole may
be provisional or not yet identified; agents may derive or revise them during
inquiry without inventing an incumbent. Once identified, independently governed
axes receive independent packets with their interactions preserved. Include a
`square` hole only when evidence establishes two independently compositional
directions; a provisional label cannot waive that acceptance obligation.

## Recommended phases

### Discover

Spawn 2-6 relevant read-only specialists in parallel.

The world cartographer identifies:

```text
representative implementations
carriers and operations
sanctioned observations
candidate equations
known non-laws and counterexamples
stable structure and varying parameters
distributed owners and bypasses
```

Do this before categorical selection.

### Nominate

Require every retained recognition to state:

```text
current encoding relation
nearest false friend
discriminating law
generalization dividend
observation-preserving transition witness
```

Every candidate packet also names evidence, prerequisites, card disposition,
residual obligations, invalidators, resource bounds, and falsifiers.

### Synthesize

Wait for every required packet. Reject stale packets whose artifact state no
longer matches.

The root synthesizes exactly one current-context comparison and one Boundary
Artifact Contract candidate. In Actuating composition, return that nomination to
Actuating without selecting or granting mutation.

### Adversarial gate

Send the synthesized candidate and strongest ordinary alternative to
`universalist-proof-auditor`. Require it to attack:

```text
prerequisites
observation preservation
semantic ownership
bypass exclusion
competitor mediation
canonicality claim
effectivity
resource model
falsifier
invalidation policy
```

Revise, narrow, leave underdetermined, or obstruct.

### Implement

Only after the receiving authority selects a route, assign one witness seam to
`universalist-witness-implementer`.

Use one writer. Do not use parallel writers on overlapping architecture.
Implementation does not widen beyond instances governed by the same evidenced
law.

### Verify

Send the exact diff, Boundary Artifact Contract, transition witness, and proof
commands to `universalist-verifier`.

Verification independently checks the selected seam, required observations,
bypasses, residuals, invalidators, and relevant mechanic laws.

### Close

Integrate the evidence, record reclassification if the proof lease changed,
name the next seam only when scope permits it, and stop after the first verified
seam by default.

Emit a root receipt only when the independent-durability gate is live.

## Packet contract

Every child returns the compact packet defined by
`subagent-packet-contract.md`. Return distilled evidence, not transcripts,
essays, or raw logs.
