# Explicit campaign selection

Read before campaign preflight for explicit `selection=all-changed`. This is
Elenctic's owner-approved exception to the default unchecked-file partition in
campaign.md.
All other campaign, worker, engineering, authority and provenance requirements
remain in force. It creates no new worker or native review-credit kind.

## Selection is independent of Viewed

Bind `selection=unchecked | all-changed` in the existing campaign working set at
the initial complete inventory cut. Absence means `unchecked`, including legacy
campaigns. Resolve it independently from workflow and the actual PR selector.

| Selection | Frozen selected set | Frozen excluded set |
|---|---|---|
| `unchecked` | Every path whose initial state is not VIEWED | Initially VIEWED paths |
| `all-changed` | Every path in the complete current PR changed-file inventory | Empty |

For all-changed, campaign.md's references to selected-as-unchecked and pre-Viewed
exclusions use this explicit partition instead. Retain the original Viewed map
as observed UI state, not review evidence or a selection filter. Never unmark
files to manufacture work. Renames, deletions, generated/binary paths and causal
unchanged dependencies retain their existing treatment; none silently disappears.
Whole-PR credit still requires complete admitted evidence and reconciled material
interactions, never merely an empty exclusion set.

Freeze the selected mode/partition in the brief, canonical assignments and final
coverage note alongside existing policy/context/campaign identities. The fresh
campaign instance and selected digest remain real; no worker-v1 identity extension
or invented receipt is necessary. Resume the original partition, not current
checkboxes. Changing selection requires explicit new-cut authority, a new campaign
instance/preparation and revalidation; output-workflow switching alone cannot do it.
An empty changed inventory does not supply a vacuous approval or a confirmation.

`for construction` still does not request fresh review. A selection argument alone
cannot turn feedback-only analysis into a new campaign; only explicit fresh-review
intent does so.
