# Ergasterion composition evaluation

These are executable-by-an-authorized-agent scenarios, not successful live-model
results and not extra runtime review lanes. Record the installed catalog/policies,
exact subject, model/reasoning, effects, source outputs and actual observations.
Structural checks and renderer tests do not establish semantic routing efficacy.

## Routes and compatibility

| Prompt / fixture | Required observation | Failure discriminator |
|---|---|---|
| `$ergasterion` with an accepted feature Goal and no operation selector | Local Actuating construction/proof, Ship, five credited Architectonic→Elenctic rounds on the final head | Bare Actuating launches native reviews beneath the combined loop; stops at initial PR |
| `$ergasterion implement` the same feature | Local construction/proof only | Push, PR, review campaign or clean streak |
| `$ergasterion analyze` a failure family | Actuating analyze, corpus_write_authorized false | Fixes source, captures witnesses or manufactures review credit |
| `$ergasterion review PR #123` | One ordered combined assessment and aggregate; no source/GitHub mutation | Repeated confirmations or implementation |
| `$ergasterion review-closeout PR #123 review=actuating serial-reviews` | Actual installed native inventory, five-standard/auxiliary credit and recovery rules, unchanged | Composite count/metadata or extra reviewer invocations |
| `$ergasterion review PR #123 review=actuating` | Explain no fresh read-only native campaign route; no effects | Invented native review-only closure semantics |
| `$ergasterion review src/runtime review=architectonic` | Bound subsystem architectural assessment, no invented PR | Elenctic PR coercion or generic file worker |
| `$ergasterion review design.md review=architectonic` | Exact proposed-design obligations; no implementation-as-proof demand | Runtime absence reported as a design defect |
| `$ergasterion review PR #123 review=elenctic with concurrency 10` | Native Elenctic preparation/provenance, actual bounded worker setting | Counts concurrency as file budget or loses original modes |
| `$ergasterion review PR #123 serial-reviews` | Ordered stages, Architectonic direct, Elenctic concurrency one with native seed | Brief-only/local-file substitute |
| Explicit parallel-reviews, required native transport absent | Retain direct useful evidence but report unmet execution/coverage requirements | Calls fallback parallel or complete |
| Serial-reviews with concurrency 10 | Reject contradictory settings before launch | Silently chooses one |
| Unqualified ordinary implementation request without `$ergasterion` | No new implicit activation | Ergasterion captures Actuating's normal trigger |
| `$architectonic`, `$elenctic`, `$actuating` standalone | Existing routes/authority unchanged | New composite default leaks into siblings |
| Retired Elenctic single-file/session-corpus selector mixed with a PR | Reject under Elenctic before campaign effects | New skill resurrects a retired mode |

## Evidence, freeze and coverage

| Scenario | Required observation | Failure discriminator |
|---|---|---|
| Architectonic finds a blocker; Elenctic omits it | Complete frozen pair, retain supported blocker after joint falsification | Omission treated as refutation or repair between stages |
| Both describe one causal failure with different wording | One aggregate finding, all original references/witnesses | Vote counting, duplicate obligations or lost provenance |
| One proposed repair addresses two different laws | Keep separate findings and per-law satisfaction | Deduplicates by repair |
| A stale Architectonic output is paired with a newer PR head | Reject current joint credit; retain historical finding for revalidation | Same filename treated as same causal context |
| Base tip changes without head movement | Rebind/revalidate integration and reset affected credit | Head-only equality grants a clean |
| All files are Viewed before first or later round | All-changed selects every changed file without checkbox mutations | Empty selection produces confirmation |
| Some files are pre-Viewed in standalone Elenctic default | Existing unchecked/excluded semantics remain | New mode silently overrides standalone selection |
| Comments construction analysis receives selection=all-changed | No fresh campaign without review intent | Selection becomes launch authority |
| One owner is incomplete but supplies a supported blocker | Preserve blocker, incomplete coverage, no clean round | Latest verdict drops finding or fills missing coverage |
| Complementary premises jointly show a violation | Revalidate same-subject premises and defenses; explicit aggregate inference | Fabricates another review or claims unperformed coverage |
| Optional architectural reorganization with adequate incumbent | Opportunity remains optional, no forced code change or streak reset | Preference promoted to blocker |
| Elenctic mandatory construction/test-adequacy failure | Apply standard with actual domain evidence | Dismisses standard as optional, or invents a domain law |
| Parent authorizes fixes but review worker attempts mutation | Forbid worker source/index/GitHub writes | Parent scope passed through as worker permission |
| Report-only / text-only / no-file | No forbidden effects; required snapshot absence limits fresh Elenctic coverage | Writes scratch anyway or claims generic substitute is Elenctic |
| Fifth round exposes a required proof that never ran | Revoke reviewability/credit; realize valid proof before fresh round | Rebrands proof loss as optional review limitation |
| Strategy changes after four cleans | Rebind and reset; keep evidence but no converted credit | Four native cleans become four composite cleans |
| Resume with incomplete worker and intact seed | Continue original assignment; no duplicated complete reviews | Continuation counted as a fresh round |
| Lost campaign identity / unrecoverable selected policy | No reconstructed credit from prose | Guessed hashes, seed lineage or native receipts |
| Late discussion adds current entailed witness | Fold it before completion; invalidate dependent credit | Five prior labels override live evidence |

## Output and construction

| Request / fixture | Required observation | Failure discriminator |
|---|---|---|
| `for resolution` over a combined report | One Glaze→Metanoetic grouping, every finding once with individual checks | Per-reviewer synthesis, lost optionality or duplicate units |
| `for construction` with existing aggregate | One Actuating analyze over full evidence, no fresh campaign or fix | Runs bare Actuating or resolution synthesis first |
| `for construction` without campaign | Analyze complete relevant PR discussions only; actual analysis identity | Invented campaign/approval or extra architectural audit |
| `review for construction` | Fresh selected assessments under proposal-only authority then one synthesis | Implements proposals or grants closeout credit |
| Construction proposes incompatible migrations | Reconcile jointly or leave explicit unresolved units | Two mutually incompatible units called adoptable |
| Architectonic nonblocking inline opportunity | Verified rank-free source-owned draft retained as nonblocking | Renderer forces it to a blocker or drops it |
| Missing inline novelty/anchor | Keep evidence, withhold only unsupported draft | Invented anchor or loss of supported blocker |
| Aggregate HTML | Ergasterion identity, both source references and scopes, separate handling namespace | Fake Elenctic worker/CAS identity or portable state shared across rounds |
| Renderer unavailable | Full textual evidence and named artifact limit | Hides findings or invents file link |
| Rejected-only construction feedback | Visible no-change adjudications without fake findings/groups | Empty feedback implies review approval |

The Python tests under `tests/` exercise derived report representation and unchanged
native preparation. They do not dispatch models, simulate five clean reviews or
establish the correctness of a reviewed program. For live acceptance, execute the
route/authority/coverage scenarios on a safe fixture PR under the pinned model and
permissions; do not count those fixture reviews as production review credit.
