# Native review proof boundary

The [native review route](../reviews.md) owns invocation, native artifact readback,
and exact-handle recovery. There is no CAS receipt requirement for new work.

```text
a process is not a completed review
an exit status is not a semantic verdict
rendered prose is not a native structured review object
attributed native output is not finding truth or review credit
```

Codex owns its thread/turn identities, original review output, configuration
responses, native artifact, and lifecycle observations. The host owns the actual
process/dispatch observation. The caller binds that execution to the immutable Git
subject, exact instructions/absence, scope, and request, then decides review credit,
finding applicability, repairs, publication, and closure.

A native result does not contain a CAS workflow echo, strong-principal assertion,
backend class, or CAS runtime-compatibility receipt. Do not fabricate those fields.
Use the direct owner evidence with the caller's existing request association;
copying it into Ledger or another event log does not strengthen its authority.

A request digest does not deliver the hashed context or prove that a reviewer saw it.
Repository sources and references accessible through the native reviewer are
evidence; parent-only conversation premises are not implicitly inherited.
Distinguish an accessible accepted source from an opaque digest or an unresolved
reference. The same diff under different compatibility contracts cannot be
distinguished by digest alone. Retain material access limitations without claiming
review of an undisclosed premise. This adds no context packet, prompt argument,
review gate, attempt, or retry. Native standard and exact auxiliary instruction
bytes remain unchanged.

For interrupted campaigns, resolve the exact process/thread/turn and native result
before deciding recovery. Summaries or claimed counts never reconstruct execution
evidence. If required evidence cannot be resolved, the caller's fresh-wave rule
applies after possibly live work is resolved. A native invocation is not a replay
of arbitrary historical configuration. Old CAS records remain historical evidence
under their original contract, not a supported alternate executor or native credit.
