# Refine

## Mission

Own one bounded skill-package edit that changes future behavior with the least
semantic surface.

```text
evidence -> weakness -> weakest sufficient intervention -> package edit -> observation
```

`$refine` is the sole writer in the user-owned skill-optimization loop.

## Admission

Require either:

- a complete `$tune` handoff; or
- a direct user-authorized edit with target, objective, constraints, and
  observable success condition.

Bind the target package and current artifact state before editing. Preserve
stable decision-contract IDs and all unrelated behavior.

## Intervention order

Prefer, in order:

1. remove a contradicted or redundant clause;
2. sharpen an activation, routing, authority, stopping, or proof boundary;
3. move conditional detail behind an existing direct resource link;
4. add the smallest missing conditional resource or regression probe;
5. introduce new machinery only when the evidence proves weaker edits cannot
   produce the required decision delta.

Do not optimize for textual minimality when it creates a semantically broader
rule.

## Mandatory progressive-disclosure proof

After any package edit, run these behavioral probes:

```text
common-path probe
  the ordinary route succeeds from SKILL.md alone

conditional-path probe
  each non-common resource is directly linked beside its exact loading condition

near-miss probe
  a similar request outside that condition neither loads the resource nor
  changes ownership

integrity probe
  no orphaned resource, duplicated full treatment, broken relative link,
  always-loaded worker-only procedure, or hidden must-level obligation remains
```

A failure blocks completion or requires a narrower edit. Do not add a receipt,
schema, validator, or CLI solely to record these probes; retain a compact
validation disposition in the PR evidence.

## Conditional disclosure

Load [references/weakness-selection.md](references/weakness-selection.md) only
when candidate interventions differ in semantic scope, a short edit would
introduce a broad rule, or a regression guard risks overfitting.

The complete pre-split contract is preserved byte-for-byte in
[FULL_CONTRACT.md](FULL_CONTRACT.md). Do not load it for the common edit path.
Load it only for exact artifact schemas, Ledger-backed validation, historical
compatibility, publication mechanics, or an unported edge route. Its
frontmatter is archived source, not a second skill definition.

## Completion

Report the changed decision surface, why the intervention is the weakest valid
one, the probes run, the named post-change observation, and any residual
uncertainty. Do not claim improvement from package shape alone.
