# Review Fold

## Mission

Turn witnessed falsification pressure into one immutable classified
Counterexample Set.

```text
source evidence + current Goal + current Construction
-> classify and quotient
-> counterexample-set/v1
-> no mutation authority
```

## Common path

1. Bind the exact source, current Goal, current Construction, subject identity,
   and artifact state.
2. Extract concrete claims and evidence; raw prose is not yet a counterexample.
3. Classify each claim as supported, rejected, duplicate/subsumed, obsolete,
   needs evidence, blocked, or outside the current Goal.
4. Group supported instances that share one governing law, owner, cause, and
   repair consequence into one counterexample class.
5. Preserve disagreements and unresolved evidence rather than forcing closure.
6. Carry still-applicable classes across an explicit source revision; do not
   silently reset them.
7. Emit one `counterexample-set/v1` bound to the exact Goal, Construction,
   subject, and source.
8. Return to `$actuating` for evaluation and any successor Construction.

A counterexample proves a current law or realization is falsified. It does not
select the replacement.

## Conditional disclosure

The complete pre-split contract is preserved byte-for-byte in
[FULL_CONTRACT.md](FULL_CONTRACT.md). Do not load it for a small, already-bounded
finding set.

Load it only for:

- exact disposition taxonomy and quotienting edge cases;
- counterexample-set schema, canonical identity, and Ledger operations;
- multi-source carry-over, revision, supersession, and applicability rules;
- review-thread resolution or Construction-integration details;
- an unported edge route.

Its frontmatter is archived source, not a second skill definition.

## Guardrails

- Do not convert suggestions or preferences into witnessed falsifiers.
- Do not create one class per comment when one law explains them.
- Do not select architecture, repair, work nodes, or mutation.
- Do not count review attempts or clean streaks.
- Do not resolve a source thread merely because its class was recorded.
